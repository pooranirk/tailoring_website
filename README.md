# 👑 Priya Stitchique - Royal Boutique & Tailoring Studio

A bespoke, luxury tailoring management web application created with **HTML5, Vanilla CSS3, and Vue.js 3**.

---

## 🌟 Key Features

1. **Grand Royal "P" Logo**:
   - Custom-crafted vector monogram featuring a 3-point royal crown, gold gradient filigree, golden sewing needle piercing the letter "P", and flowing embroidery thread swirl.

2. **Client Order Details & Tracking**:
   - **Client Name**
   - **Outfit Type**: Specialized for:
     - 🪡 **Chudi** (Punjabi suits, straight cut, salwar)
     - 💎 **Aari Work Blouse** (Bridal Maggam & hand embroidery)
     - ✂️ **Blouse** (Princess cut, pattern blouse, boat neck)
     - ✨ **Lehenga** (Bridal flared lehenga, can-can skirt, choli)
   - **Payment Status**: Instant **PAID** (green badge) or **UNPAID** (red alert badge), toggleable with 1-click!
   - **Contact Details**: Direct **WhatsApp** button (pre-fills client name, outfit type, and balance dues), plus click-to-call button.
   - **Stitching Amount & Delivery Date Tracker**.

3. **No External Images Needed**:
   - Built with high-end SVG vector graphics, glowing gold accents, and luxury typography (`Cinzel`, `Playfair Display`, `Plus Jakarta Sans`).

4. **Features & Controls**:
   - **Live Search**: Search by client name or phone number.
   - **Filter by Outfit**: Filter between All, Chudi, Aari Work Blouse, Blouse, and Lehenga.
   - **Filter by Status**: View Paid only, Unpaid only, or All.
   - **View Modes**: Switch between **Cards Grid** and **Professional Table View**.
   - **Theme Switcher**: Royal Velvet Midnight Dark Mode 🌙 & Luxury Cream Pearl Light Mode ☀️.
   - **LocalStorage Persistence**: All new orders and updates are automatically saved locally.
